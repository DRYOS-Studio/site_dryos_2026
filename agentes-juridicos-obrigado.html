DRYOS Agentes jurídicos
— Passo a passo

Instale os agentes e faça o teste.

Recebemos suas respostas. Siga os passos abaixo; se travar em algum, fale com a gente pelo WhatsApp.

Não conseguimos registrar seus dados agora, mas o guia está liberado. Se quiser que a gente fale com você, mande um oi no WhatsApp.

Antes de começar: você precisa de um plano pago do Claude (Pro ou superior); o plano gratuito não inclui o Claude Code. O que os agentes entregam é rascunho: o advogado revisa e assina, e a responsabilidade técnica continua dele (EAOAB, art. 32).

  1. Abra o Terminal

    Tecle Cmd + Espaço, digite "Terminal" e aperte Enter.

  2. Instale as ferramentas da Apple

    Elas trazem o git e o Python. Uma janela vai pedir confirmação: clique em Instalar. Se aparecer "already installed", pode seguir.

    xcode-select --install

  3. Instale o Claude Code

    curl -fsSL https://claude.ai/install.sh | bash

  4. Crie uma pasta para os agentes

    mkdir -p ~/agentes-juridicos && cd ~/agentes-juridicos

  1. Instale o Git for Windows

    Baixe em git-scm.com/downloads/win e avance com as opções padrão.

  2. Instale o Python

    Abra a Microsoft Store, busque "Python 3" (publicado pela Python Software Foundation) e clique em Obter.

  3. Abra o PowerShell

    Tecle Windows, digite "PowerShell" e aperte Enter.

  4. Instale o Claude Code

    irm https://claude.ai/install.ps1 | iex

  5. Crie uma pasta para os agentes

    Feche e abra o PowerShell de novo, e rode:

    mkdir -Force $HOME\agentes-juridicos; cd $HOME\agentes-juridicos

Instalar os agentes

  1. Abra o Claude Code na pasta

    Na primeira vez, o navegador abre para você entrar com a sua conta do Claude.

    claude

  2. Adicione o catálogo da DRYOS

    Dentro do Claude Code:

    /plugin marketplace add DRYOS-Studio/agentes-juridicos

  3. Instale os agentes

    Quando o Claude perguntar, escolha User scope.

    /plugin install agentes-juridicos@dryos

  4. Confira

    Digite /plugin, vá até a aba Installed e veja agentes-juridicos na lista. Tecle Esc para sair.

Fazer o teste

Cole a mensagem abaixo no Claude Code. O caso é fictício; não use dados de cliente real no teste. O agente pode fazer perguntas antes de redigir e depois entrega a minuta com as averbações e o checklist.

Use o agente divorcio-consensual. Caso fictício para teste: Ana Souza e Bruno Lima, casados desde 2015 no regime de comunhão parcial, sem filhos, querem se divorciar em cartório. Têm um apartamento em Niterói (R$ 400.000) que fica com Ana, que paga R$ 200.000 a Bruno. Sem pensão entre eles. Redija a minuta da escritura.

Para chamar outro agente, diga o nome dele no pedido, por exemplo: "Use o agente bpc-loas para…".

Perguntas frequentes

Apareceu "python3: command not found"

Os agentes de cálculo usam o Python. No Mac, rode xcode-select --install de novo. No Windows, instale o Python pela Microsoft Store, feche e abra o PowerShell. Se ainda falhar, peça ao Claude: "faça a conta sem usar Python".

E o sigilo dos meus clientes?

O que você digita no Claude Code vai para os servidores da Anthropic, a empresa que faz o Claude. Anonimize nomes e documentos quando puder e siga a política do seu escritório.

O Claude pediu permissão para rodar um comando

Os agentes só precisam rodar python3 (para cálculos) e criar os arquivos da peça na pasta dos agentes. Não aprove comandos que você não entende, e não abra no Claude Code documentos de origem desconhecida.

Deu "/plugin isn't available in this environment"

Você está no app de desktop ou numa sessão na nuvem. Use o Terminal (Mac) ou o PowerShell (Windows), como no passo a passo.

— Além da peça

Os agentes redigem a peça. A rotina em volta dela também pode rodar sozinha.

A DRYOS automatiza a rotina do escritório que não é advocacia: atendimento no WhatsApp, cobrança de honorários, sistemas conectados e relatórios. O diagnóstico é gratuito e leva 30 minutos.
